# Jaspr Storybook runtime

Generic MIT-licensed Dart package. Keep application code and assets out of this repository.
The companion framework is `@codegrowers/storybook-jaspr-vite` in the
Code-Growers/storybook-jaspr-vite repository. Keep releases and browser protocol
compatible. Run Dart formatting, analysis, tests and publication dry-run.
Verify runtime changes in the companion Storybook example with browser tools.
